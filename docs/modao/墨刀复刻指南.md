## 二、发布（需账号本人操作，约 1 分钟）

1. 登录 modao.cc 打开 https://modao.cc/proto/design/pb2mcpVbbL7mt5uEarUH ；
2. 左上角项目名"未命名原型"→ 重命名为 `FactLens 事实透镜（前台+后台）`；
3. 右上角 **分享 → 链接分享 → 任何人可查看**，复制链接；
4. 把链接填入博客《FactLens第二次团队作业》"原型在线预览（墨刀）"处；
5. 无痕窗口自测：无需登录即可打开并切换页面。

## 三、如何修改 / 重新导入

- **微调**：在墨刀编辑器内点击画板（代码组件）→ 编辑 HTML 源码保存即可；
- **重新生成画板**：`python tools/modao_build_pages.py`（用 Edge 重新渲染 13 个静态页）；
- **重新导入墨刀**：在墨刀 头像 → 令牌设置 生成 Token，然后 `set MODAO_TOKEN=令牌` + `python tools/modao_import.py`（会新建一个项目）；
- 静态画板源码在 `docs/modao/pages/`，导出参数钩子（`?fill=` / `?checking=1` / `?open=`）在 `docs/prototype/` 两个 HTML 的启动脚本末尾。

## 四、验收要点

1. 前台 5 页 + 后台 5 页 + 3 个弹层交互态齐全；
2. 结论四色、主色渐变与 HTML 原型截图一致；
3. 分享链接免登录可访问；
4. 页内按钮/弹层的完整交互演示见 HTML 交互版：https://doinb1234.github.io/FactLens/prototype/index.html 。
