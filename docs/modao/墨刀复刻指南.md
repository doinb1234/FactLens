# FactLens 墨刀原型复刻指南

> 目的：按本指南把 HTML 高保真原型（`docs/prototype/`）复刻到墨刀（modao.cc），满足作业"必须使用专用原型工具"的硬性要求。
> 预计耗时：一人 **30～40 分钟**。全部页面素材（截图、文案、颜色）已备好，照稿摆放即可。

## 一、准备工作（约 5 分钟）

1. 注册/登录 [墨刀 modao.cc](https://modao.cc)（手机号注册，免费版即可）；
2. 新建原型项目：**Web 项目 · 自定义尺寸 1440 × 900**；项目名：`FactLens 事实透镜（前台+后台）`；
3. 把本指南所在目录下的截图按页对照摆放；文字文案直接复制本指南每页的"文案要点"；
4. 完成全部页面后：右上角 **分享 → 链接分享 → 任何人可查看**，复制链接填入博客"原型在线预览链接"。

## 二、全局设计规范

| 项 | 规范 |
| --- | --- |
| 主色 | #0F766E（深青）～ #14B8A6（浅青）渐变；按钮/选中态用渐变 |
| 背景 | #F6F9F8；卡片白色 + #E2E8F0 边框 + 圆角 14px |
| 正文 | 15px / #0F172A；次要文字 13px / #64748B |
| 结论四色 | 确认属实 #15803D（绿底 #DCFCE7）；确认不实 #B91C1C（红底 #FEE2E2）；部分属实 #B45309（琥珀底 #FEF3C7）；暂无法核实 #475569（灰底 #E2E8F0） |
| 徽章 | 圆角胶囊（border-radius 999px），带 7px 圆点 |
| 字体 | 思源黑体 / 系统默认 |

## 三、前台应用（5 个画板）

对照截图：`../design/assets/shots/front-home.png` 等（同目录名对应）。

### 页面 1：核查页-输入态（front-home.png）

- **元素**：顶部导航（Logo + 开始核查/历史记录/关于）；主标题"让真相，清晰一点。"；输入卡片（多行文本域 + 字数"0 / 2000" + 3 个示例胶囊按钮 + 右侧"开始核查"按钮）；页脚。
- **文案要点**：示例三条：①"地球是太阳系的一颗行星" ②"多喝热水能治感冒，感冒吃抗生素好得快" ③"手机辐射会导致脑癌，睡觉时手机放床头很危险"。
- **热点交互**：
  - 三个示例胶囊 → 点击后文本域填入对应文字；
  - "开始核查" → 跳转【页面 2 核查中】；
  - 导航"历史记录" → 跳转【页面 4】；"关于" → 跳转【页面 5】。

### 页面 2：核查中（四步进度）

- **元素**：卡片内标题"FactLens 正在核查…"；四个步骤节点横向排列：1 拆解断言 → 2 检索证据 → 3 综合判定 → 4 生成报告（第 1 个高亮/呼吸动画）；下方灰字"正在把原文拆解成可独立查证的断言…"。
- **热点交互**：本页为过渡态，热点指向【页面 3 报告页】即可（墨刀用"页面跳转"）。

### 页面 3：核查报告页（front-report.png）

- **元素**：
  - 顶部：结论大胶囊（"部分属实"，琥珀色底 + 圆点）、"模型判定"蓝色徽章、右上角"核查时间：2026-11-21 20:02"；
  - 摘要段落；判断理由段落；
  - 三栏卡片：✅ 支持 / ❌ 反驳 / ❓ 不确定因素（各 2～3 条要点）；
  - "断言与证据（逐条核对）"：2 张断言卡片，每张含"断言 1"序号标签 + 断言文字 + 来源列表（来源标题链接 + 域名灰字 + 摘要）；
  - "全部来源（已按 URL 去重）"列表；
  - 底部按钮：📋 复制报告、↺ 重新核查。
- **文案要点**：直接复制 front-report.png 截图中的文字（示例 2"多喝热水"报告）。
- **热点交互**："复制报告" → 弹 toast"报告已复制到剪贴板"（墨刀用提示气泡组件）；"重新核查" → 跳转【页面 1】。

### 页面 4：历史记录页（front-history.png）

- **元素**：标题"历史记录"+ 副标题；搜索框；右上"清空全部"按钮；3 条记录卡片（时间 + 原文 + 结论徽章 + 重新核查/删除按钮）。
- **热点交互**：记录卡片"重新核查" → 跳转【页面 1】；"删除" → 卡片消失（交互态画板）。

### 页面 5：关于页（front-about.png）

- **元素**：标题"关于 FactLens"；六宫格功能卡（断言拆解/证据检索/四值判定/透明报告/历史记录/降级可用，各含一句话）；"核查原则"列表（5 条）；琥珀色"当前局限"声明框（4 条）。

## 四、后台管理（5 个画板 + 2 个弹层状态）

对照截图：`../design/assets/shots/admin-*.png`。

### 页面 6：管理员登录（admin-login.png）

- **元素**：居中白色卡片：Logo"FactLens 管理后台"、副标题、账号输入框（预填 admin）、密码输入框、渐变"登录"按钮、底部浅青提示条"原型演示：点击登录即可进入"。
- **热点交互**："登录" → 跳转【页面 7 数据概览】。

### 页面 7：数据概览（admin-overview.png）

- **元素**：左侧深青侧边栏（Logo + 菜单：数据概览/核查记录/证据源管理/系统配置 + 底部管理员信息"admin（超级管理员）"）；顶部标题栏"数据概览"；
  - 四张统计卡：今日核查 128、累计核查 3,452、模型判定占比 76%、平均耗时 8.6s（各带趋势小字）；
  - 左大图"近 7 日核查量趋势"折线图（可用墨刀折线图组件）、右"结论分布"环形图 + 图例（39.7% 属实 / 24.9% 无法核实 / 20.0% 部分属实 / 15.4% 不实）；
  - "最近核查记录"表格（5 行）。
- **热点交互**：侧边栏菜单互跳；表格行"详情" → 跳转【页面 8 并弹抽屉态】。

### 页面 8：核查记录（admin-records.png + 抽屉态）

- **元素**：筛选栏（结论下拉 + 关键词输入 + 查询按钮 + "当前显示 8 / 138 条"）；表格（ID/时间/原文截断/结论徽章/断言/来源/判定方式徽章/操作：详情、删除）；底部分页（共 138 条）。
- **弹层状态（交互态画板）**：点击"详情" → 右侧滑出抽屉（记录 ID、时间、判定方式、原文、摘要、断言与证据）；点击"删除" → 居中确认弹窗（"确定要删除核查记录 #3452 吗？"取消/删除）。

### 页面 9：证据源管理（admin-sources.png + 新增弹窗态）

- **元素**：三张统计卡（高权威 26 / 一般可信 41 / 黑名单 7）；"＋ 新增证据源"按钮；表格（域名/类别/权威等级徽章/状态开关/备注/更新时间/操作）。
- **弹层状态**：新增/编辑弹窗（域名、类别下拉、权威等级单选：高/中/低/黑名单、状态单选、备注、取消/保存）。

### 页面 10：系统配置（admin-config.png）

- **元素**：两列卡片（大模型配置：接口地址/模型名/密钥掩码 + 👁显示按钮/温度；检索参数：结果数 4/超时 20s/LLM 超时 60s/原文上限 2000 字）；通栏"服务状态"卡（接口地址、健康检查"运行正常"绿点、模型可用性 true、当前模型 glm-4.7-flash、最近检查时间 + 重新检查/保存配置按钮）。

## 五、发布与验收

1. 全部画板完成 → 分享 → 链接分享 → **任何人可查看**；
2. 自测：手机/无痕窗口打开分享链接，确认无需登录即可浏览；
3. 把链接替换到博客《FactLens第二次团队作业——原型设计+概要设计》的"原型在线预览链接"处（当前为占位符 `【墨刀链接占位-待替换】`）；
4. 验收要点：前台 5 页 + 后台 5 页 + 弹窗/抽屉交互态齐全；结论四色、主色渐变与截图一致；热点跳转方向正确。
