          关于 FactLens

          Fact（事实）+ Lens（透镜）—— 一条说法是真是假，放到透镜下看清它的每一个组成部分。

          🧩

          断言拆解

          把一段消息拆成 1~3 条可独立查证的断言，逐条核实，不笼统下结论。

          🌐

          证据检索

          为每条断言联网检索证据，保留标题、链接、摘要与域名，来源可追溯。

          ⚖️

          四值判定

          结论只取四种之一：确认属实 / 确认不实 / 部分属实 / 暂无法核实，绝不编造。

          📋

          透明报告

          报告给出摘要、理由、支持与反驳要点、不确定因素，可一键复制分享。

          🧾

          历史记录

          刷新后仍能查找、删除记录，或用原文重新核查。

          🛡

          降级可用

          模型不可用时自动降级为“搜索 + 规则判定”，服务始终可用、结论趋于保守。

          核查原则
          • 只依据证据：结论只来自检索到的证据与模型分析，无证据不强判。
          • 证据不足就明说：拿不准时给出“暂无法核实”，并列出不确定因素。
          • 来源可复核：每条证据都可点击回到原网页，核对上下文与时间。
          • 区分权威：官方/权威域名在判定中加权，一般网页仅供参考。
          • 透明告知：报告标注判定方式（模型判定 / 降级判定）与核查时间。

          ⚠️ 当前局限（首版如实声明）

          • 判定基于公开网页检索与模型推理，不能替代权威机构与专业核查；
          • 首版只接收文字（≤2000 字），暂不支持图片、视频与文档；
          • 未配置模型密钥时结论偏保守，多数标为“暂无法核实”；
          • 历史记录暂存于浏览器本地，换设备不可见（迭代二迁移服务端）。
